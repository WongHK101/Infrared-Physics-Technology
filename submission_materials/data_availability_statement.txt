Data Availability Statement

Current factual draft (2026-10-21; dataset access still needs to be established):

UAV-TAlign-12K is jointly owned by Nanning Normal University and Guangxi University and is prepared for release under the Creative Commons Attribution 4.0 International license. The official evaluation split contains 6,037 integrity-checked RGB-infrared pairs from the 6,039-pair collection. The image archive awaits repository deposit and assignment of an access link. A separate reproducibility package contains the official manifest, metadata, integrity summaries, evaluation code, and numerical figure sources for submission as supplementary material. Original UAV-TAlign software is licensed under Apache-2.0; third-party components retain their respective licenses.
