# Submission Access and AI Disclosure Check

## Dataset and code access

The dataset is jointly owned by Nanning Normal University and Guangxi University.
CC BY 4.0 remains the dataset/content license. Original project software remains
Apache-2.0, with upstream licenses preserved. The ownership update does not transfer
third-party rights or change software copyrights.

The project release materials do not yet identify a functioning dataset DOI or
reviewer-access URL. A public code repository is not a deposit of the image archive.
Keep current-state, reviewer-access, and public-release Data Availability text separate.

An offline supplementary code/evaluation package is prepared as a delivery option.
It contains source code, manifests, integrity summaries, numerical figure sources,
and environment/weight instructions, but no raw image collection, weights, credentials,
or experiment JSONL logs. It is not an anonymized package: legal attribution and
upstream license notices are preserved.

Whether an author-identifying URL is suitable during review depends on the journal's
current review model. The IP&T Guide for Authors could not be read on 2026-10-21:
ScienceDirect returned an access challenge/error. Accordingly, this audit does not
claim to have confirmed single- or double-anonymized review. Check the live "Peer
review" section or obtain editorial confirmation before choosing the review version.
If double-anonymized review is required, identifying dataset ownership and URLs also
need an appropriately separated review version; anonymous author names alone are
not sufficient.

## AI disclosure

The current official Elsevier policy (updated June 2026) requires disclosure of
substantive generative-AI manuscript assistance. Basic spelling/grammar checking
is exempt; this project's translation, organization, code, and schematic work
exceeds that exemption.

The manuscript retains a short declaration immediately before the references.
The experimental setup describes coding and data-visualization assistance.
The two explanatory schematic captions identify Codex-assisted layout work.
Captured UAV photographs and experimental measurements are not generated by a
generative image model.

Authors must verify the final wording, tools used, scientific content, rights, and
submission approval. Do not assert complete human review or a nonexistent data
deposit merely to make the submission package appear finished.
