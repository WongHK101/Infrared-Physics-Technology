\section{Experimental Setup}

\subsection{Baseline Suite}

We evaluate seven representative baselines without UAV-TAlign-12K-specific adaptation; all learned
methods use public pretrained weights. The suite covers three method families. SIFT and AKAZE provide
classical keypoint references, each followed by robust homography estimation. RIFT2 provides an
infrared-visible-specific classical reference through its Python implementation
\cite{li2023rift2,yagmur_rift2_python}. The modern suite
contains Kornia LoFTR, RoMa outdoor, XoFTR-640, and raw MINIMA
\cite{sun2021loftr,edstedt2024roma,tuzcuoglu2024xoftr,ren2025minima}.

Raw MINIMA uses the \texttt{minima\_roma} checkpoint family with the full RoMa branch. RoMa uses
the public outdoor full model, and XoFTR uses its 640-resolution visible-thermal checkpoint. LoFTR
uses Kornia's public outdoor-pretrained model. Unified inference wrappers standardize image I/O,
model output, homography fitting, and result schemas while preserving each pretrained model.

\subsection{Geometric Fitting and Deployment Profiles}

All pairwise methods use USAC-MAGSAC for homography estimation. The shared profile uses a
3.0-pixel reprojection threshold, 0.999 confidence, and 10,000 maximum iterations;
RIFT2 retains its separately specified 5.0-pixel profile. Spatial match coverage is measured on
the same $4\!\times\!4$ grid for all methods. \ref{sec:metric_aggregation} defines the
fitting diagnostics and their aggregation.

RIFT2 uses its frozen resize-aware profile: \texttt{max\_dim=1200}, \texttt{npt=2000},
\texttt{patch\_size=64}, Lowe ratio 0.95, and USAC-MAGSAC with a 5.0-pixel reprojection threshold.
LoFTR uses resize-aware inference with a longest image dimension of 1200 and automatic mixed
precision. Runtime and fitting diagnostics are reported for these declared deployment profiles.

\subsection{Protocol Validation}

Two controlled experiments evaluate the scene protocol on frozen formal outputs. Five-fold
leave-frame-out analysis partitions accepted frame hypotheses deterministically, withholds one
fold, recomputes scene consensus, and measures grid displacement from the full-evidence transform.
A controlled sensitivity test applies translation, rotation, and scale perturbations at nominal
severities of 2, 5, 10, 20, and 40 pixels to three representative frames per scene. The test
records edge-overlap and gradient-NCC responses while keeping the canonical decision fixed.

Journal-scale experiments were conducted in isolated Python environments on an NVIDIA RTX 4090
workstation. The main environment used Python 3.10, PyTorch 2.0.1, torchvision 0.15.2, CUDA 11.8,
OpenCV 4.11.0, and Kornia 0.6.11; RIFT2 used an independent Python 3.11 environment.
Every run used the official manifest, fixed model weights or
interfaces, isolated output roots, and read-only raw dataset directories.

\paragraph{Implementation and visualization assistance.}
OpenAI Codex assisted with Python implementation, evaluation wrappers, result aggregation, and
plotting scripts. The reported quantities are computed by the versioned scripts from the fixed
manifest and archived run outputs. Image panels use captured UAV images, frozen homographies,
and deterministic cropping, warping, and edge-overlay operations; no generative image model
creates or modifies the captured scene content.
